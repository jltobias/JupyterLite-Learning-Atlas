# NASA ARSET Remote Sensing — Open Notebook Experiments

![Blue Marble image of Earth from the Suomi NPP satellite](https://images-assets.nasa.gov/image/GSFC_20171208_Archive_e001386/GSFC_20171208_Archive_e001386~small.jpg)

*Image: “Most Amazing High Definition Image of Earth - Blue Marble 2012.” Credit: NASA/NOAA/GSFC/Suomi NPP/VIIRS/Norman Kuring. See [NASA's image record](https://images.nasa.gov/details/GSFC_20171208_Archive_e001386) and [media usage guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/).*

An independent project to develop Jupyter notebooks and a Jupyter Book for learning to work with Earth-observation data. The goal is to complement NASA's Applied Remote Sensing Training (ARSET) program with original, runnable examples—not to reproduce ARSET course materials.

> **Project status:** This repository is currently a README-only starting point. It does not yet contain notebooks, a repository license, or a built Jupyter Book/JupyterLite site, and no project launch URLs are live. The links below identify the official learning references and tools; project launch links will be added when those deliverables are published.

## Learning tracks

The notebook collection is intended to grow beyond the introductory course. Possible original exercises include:

- **Remote-sensing fundamentals:** spatial, spectral, radiometric, and temporal resolution; image composites; projections; and basic raster analysis.
- **Disasters:** map an event with satellite observations and compare observations across dates.
- **Water resources:** explore surface-water extent, watersheds, and time series.
- **Agriculture and ecosystems:** examine vegetation indices, land cover, and seasonal change.
- **Air quality and health:** compare satellite-derived atmospheric products with place and time.
- **Wildland fire:** explore burned area, active-fire observations, and recovery.
- **Climate and change:** analyze multi-date imagery while documenting scale, uncertainty, and limitations.

The [NASAARSET repository collection](https://github.com/NASAARSET?tab=repositories) provides additional training-associated examples, including carbon dioxide, drought, air quality, machine learning, land-cover change, and reservoir management. The tracks above are ideas for this project's own future notebooks, not a claim that this repository contains or is endorsed by an ARSET course on each subject. Each notebook should identify its relationship to an official training, cite its own data and methods, and link to the relevant official materials.
