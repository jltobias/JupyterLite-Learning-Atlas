This independent book introduces the ideas and workflows behind Destination Earth through **32 small, runnable notebooks**. Read a chapter, inspect its figure, then open the same notebook in the browser lab and change an assumption.

Destination Earth is an initiative of the European Union, implemented by ECMWF, ESA and EUMETSAT. Its Platform, Data Lake and Digital Twin Engine connect users, data services and modeling capabilities. The initial twins address climate adaptation and weather-induced extremes. This book explains those roles with original examples; it does not provide a production twin or operational forecast.

## Start with something you can run

Begin with [the system lesson](../01-system.ipynb). Each notebook contains objectives, a complete experiment, numerical checks, an exercise and an interpretation. All default data are original synthetic arrays. No account or credentials are required.

The [coverage matrix](coverage.md) maps every notebook to its learning goal and identifies capabilities that remain conceptual. The [official-access guide](official-access.md) describes how an authorized export can cross into a small browser analysis without embedding credentials in a static site.

## Two ways to interact

Notebook links identify the exact Lab filename and repository source. In Lab, run cells from top to bottom; package downloads may take time. The map, terrain, globe, time and dashboard chapters include Python widgets. The standalone gallery offers responsive Canvas controls for maps, scenes, a globe, a dashboard, vector fields and time comparisons.

Published book figures are retained outputs from native clean-kernel execution. Browser execution is a distinct runtime and is reported separately. A book figure alone does not prove that a widget or package ran in Pyodide.

## A useful boundary

These lessons use browser-sized arrays and original equations. They omit coupled physics, assimilation, supercomputing, operational governance and domain validation. Follow primary references for official capabilities and current access terms. The linked Generation 2 Climate DT dataset is not used by this book ([ECMWF Generation 2 Climate DT dataset, DOI 10.21957/79c6af3105](https://doi.org/10.21957/79c6af3105); metadata context only, dataset not used).

The retained [source BibTeX references](references.bib) provide the original citation metadata.
