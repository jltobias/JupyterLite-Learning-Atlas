Urbanity helps researchers build and analyse feature-rich urban networks and graphs. This companion book makes those ideas approachable through short explanations, runnable synthetic examples, visual exhibits, and links to the real Urbanity workflows.

```{admonition} Important: browser examples are synthetic
:class: warning
The notebooks use small, constructed graphs so they can run in a browser. They explain concepts and do **not** import or execute the Urbanity package. Use the linked native tutorials for real OpenStreetMap/geospatial data, imagery, or graph machine learning.
```
