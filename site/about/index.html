Real-data maps and scene library

The Map and Scene Atlas preserves actual coordinates, sample masks, counts, units, dates and scoped terms. Local Leaflet 1.9.4 (BSD 2-Clause) supplies pan/zoom 2D; bundled Plotly.js 3.1.0 (MIT) supplies statistical columns and actual corrected terrain in WebGL. A 2D map, paginated table, full source file and attributed sample export remain alternatives. Optional OpenStreetMap street tiles are off by default; no account, tile key or remote data API is required for the local snapshots.

Corrected WUR terrain and adaptations retain CC BY-NC-SA 4.0; they are not covered by the original Atlas content's CC BY 4.0 license. Native population grids retain per-producer CC BY 4.0 citations and notices. USGS/NASA Landsat and US Census source data are public domain. JASL/UHSLC gauge data retain the producer's free-use/redistribution statement and complete warranty/liability terms. The asset ledger records exact hashes and source metadata; data sources and notices explain the scope.

Terrain height screens do not predict flooding or 2030 risk. Statistical columns are not physical buildings. Population products are independent estimates, never summed. Tract counts remain whole-tract counts. Published symbols mark approximate city anchors, never facility sites; overlapping scopes stay separate. The two 672-hour July 1994 gauge windows refer to separate station zeros; window anomalies are not MSL and are never added to terrain or AR6 projections.

The map library contains exact public source entry URLs and pinned evidence from the public repository scan. Its real-source default includes estimates, predictions and projections as well as observations. Entry checks establish document reachability only, not source runtime functionality, dataset availability or third-party services. Source-only coverage is explicit, and no external previews load automatically.

Participation means people can question the framing, change the experiment, and reject a proposed use. A visually persuasive map, a prediction, a synthetic scenario and a causal claim need different evidence. No endorsement by a referenced organization is implied.

What has a launch check established?

Where marked, an HTTP GET confirmed that an entry document returned a particular status on the recorded date. It did not verify every notebook query path, dataset, map renderer, account permission or model service. The Global Health GIS README's lowercase launch URL and the Maps-and-Spatial-Analyses README's root launcher returned 404 on November 1, 2026 and remain labeled unavailable. If a README gives no launcher, the atlas points to source and says so.

Browser runtime and saving

Default notebooks use small deterministic values, Python's standard library and IPython SVG display. First use downloads the browser Python runtime and needs network; a fresh offline browser may not start. Native executables, GPU inference and live AI providers have separate continuation routes. This atlas supplies no credentials or remote services.

JupyterLite edits live in browser storage, not in GitHub or a shared database. Download valuable notebooks before clearing browser data or changing profiles. This index uses its own storage namespace. The static Book remains useful without starting a Python kernel.
