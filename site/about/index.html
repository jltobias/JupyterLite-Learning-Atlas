What has a launch check established?

Where marked, an HTTP GET confirmed that an entry document returned a particular status on the recorded date. It did not verify every notebook query path, dataset, map renderer, account permission or model service. The Global Health GIS README's lowercase launch URL and the Maps-and-Spatial-Analyses README's root launcher returned 404 on November 1, 2026 and remain labeled unavailable. If a README gives no launcher, the atlas points to source and says so.

Browser runtime and saving

Default notebooks use small deterministic values, Python's standard library and IPython SVG display. First use downloads the browser Python runtime and needs network; a fresh offline browser may not start. Native executables, GPU inference and live AI providers have separate continuation routes. This atlas supplies no credentials or remote services.

JupyterLite edits live in browser storage, not in GitHub or a shared database. Download valuable notebooks before clearing browser data or changing profiles. This index uses its own storage namespace. The static Book remains useful without starting a Python kernel.
