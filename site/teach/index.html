A SMALL INTERACTIVE EXPERIMENT

One landscape.
Three ways to question it.

This invented 4×4 grid has arbitrary height units and assumed service-demand values. Switch views, rotate the geometry, and change an assumed water level. Every number is in the table below.

Use Tab to reach each control and arrow keys to change a slider. The 2D map and table provide alternatives to the projected 3D views. Rotation changes perspective; it does not change the data.

2D height map

Predict, then change one thing.

Which cells meet the height threshold at water level 2? Is their share of assumed demand the same as their share of area? Compare the flat map with the extrusion.

In the terrain scene, water is a flat conceptual plane. This threshold experiment ignores hydraulic connectivity, tides, drainage, roads, adaptation, observation error and people. It is not an inundation model or health assessment.
